# plush-toy 主板首板验收

本清单在 DRC、未连接项、原理图一致性均为零问题后执行。静态检查不能代替实物测试；
每项都应记录**日期、板号、实测值和结论**。

接线针序见 [WIRING.md](WIRING.md)，外购件清单也在那里。

---

## 〇、仪器与降级

现有仪器：**只有万用表**。下面每项写明降级后怎么做，以及**降级后能证明什么、不能证明什么** ——
这一列比操作本身更重要，不要把"看着正常"当成"验证通过"。

| 原本需要 | 降级做法 | 能证明 | **不能**证明 |
|---|---|---|---|
| 限流电源 | USB 电压电流表 + 充电头 | 有无短路、静态电流是否离谱 | 上电瞬间的浪涌幅度 |
| 示波器（SPI/USB 波形） | 看功能现象：能否稳定烧录、屏有无花点 | 链路基本可用 | 信号裕量。首板"勉强能用"和"留足余量"分不出来 |
| 示波器（电源纹波） | 看日志有无 BROWNOUT 或异常复位 | 没有掉到复位门限以下 | 纹波是否已经影响到模拟外设（麦克风底噪、ADC 读数） |
| 示波器（PWM 频率） | 肉眼看背光有无闪烁 | 频率高于人眼可辨 | 实际是不是 25kHz |
| 热像仪 | 红外测温枪 | 热点位置与大致温度 | 温度分布，小封装的真实结温 |

**强烈建议补两件（合计约 100 元）：**
- **USB 电压电流表** —— 首次上电看电流。板上有 `U_EFUSE` 限流和 `F_USB` 自恢复保险丝，
  配上电流表，逻辑域首次上电基本安全。
- **红外测温枪** —— 替代热像仪，且不会烫伤。

**VMOT 那一路没有任何替代品**：舵机和加热直接吃外部 5V，板上没有 eFuse 保护。
这一路只能靠**测试顺序**兜底，见第四、五节的门禁。

## 三、未上电检查（万用表，不插电）

全部在**不通电**状态下做完，再考虑上电。

| 项目 | 操作 | 通过标准 | 实测值 / 结论 |
|---|---|---|---|
| 电源短路 | 量 `TP_VBUS`、`TP_3V3`、`TP_VMOT` 各自对 `TP_GND` 的电阻 | 均不为 0Ω。**任何一路为 0Ω 就停下，先查短路再说** | |
| 电源隔离 | 量 `TP_VMOT` 对 `TP_VBUS`、`TP_VMOT` 对 `TP_3V3` | 均开路 | |
| **单点接地** | 拆下 `R_STAR`（0Ω，在 `J_VMOT` 旁），量 `TP_GND` 对 `TP_PGND` | **开路**。这是验证两个地域只在一点连通的唯一直接手段。量完装回去 | |
| I2C 上拉 | 量 `TP_SDA`、`TP_SCL` 对 `TP_3V3` | 各约 4.7kΩ。偏小说明有多余上拉 | |
| SH 座连锡 | 放大镜看 `J_EXT` / `J_MIC` 焊盘，再量相邻脚之间 | 无连锡。**`J_MIC` 的 2 脚和 6 脚都是 GND，中间三根若连到 GND 很隐蔽，必须逐脚量** | |
| 背光默认关断 | 量 `Q_LCD_BL` 栅极对 `+3V3` | 约 0Ω（100k 上拉 `R_LCD_BL_OFF` 已焊）。**开路说明该电阻虚焊，上电会直接点亮背光** | |

## 四、逻辑域首次上电（只插 USB）

> **门禁：第三节全部通过之前，不上电。**
> **第一次别插电脑** —— 插充电头配 USB 电流表。有短路时烧的是充电头，不是笔记本。

| 项目 | 操作 | 通过标准 | 实测值 / 结论 |
|---|---|---|---|
| 静态电流 | 充电头 + USB 电流表，不接任何外设 | 电流稳定在几十 mA 量级，不持续攀升、不触发 eFuse | |
| 3V3 | 量 `TP_3V3` 对 `TP_GND` | 3.3V ±5% | |
| VMOT 隔离 | 此时量 `TP_VMOT` | **0V**。有电压说明两域串了，立即停止 | |

| 启动日志 | 看首次启动日志 | 无 BROWNOUT、无反复重启；缺外设只报"不可用"不 panic | |

## 五、接外设（逐个加，每加一个回到日志确认）

> **门禁：第四节全部通过之前，不接任何外设。**

### 5.1 屏与背光

> **这一步有烧屏风险。** `J_LCD.8`（BL）到 `Q_LCD_BL` 之间**没有限流电阻** ——
> 当初按"屏模块自带限流"设计，但这个假设从未验证过。

| 项目 | 操作 | 通过标准 | 实测值 / 结论 |
|---|---|---|---|
| **背光限流确认** | **先只接一只眼**。用万用表二极管档量屏模块 BL 脚对 GND | 有压降说明内部串了电阻或直连 LED。**读不出限流电阻就先串一个 100Ω 试点亮，确认不过流再直连** | |
| 背光电流 | 单眼点亮，USB 电流表看增量 | 单屏背光增量在几十 mA 量级。**超过 100mA 立即断电，说明没有限流** | |
| 上电默认灭 | 重新上电，不做任何操作 | 背光是灭的（靠 `R_LCD_BL_OFF` 100k 上拉） | |
| 亮度调节 | `SetBrightness()` 从 0 调到 100 | 两眼亮度一致、无可见闪烁、0 时完全熄灭 | |
| 双屏显示 | 接第二只眼，40MHz SPI 连续动画 | 无花屏、撕裂或颜色错位。**有花点先退回 20MHz**（`DISPLAY_PCLK_HZ`） | |

### 5.2 麦克风与喇叭

| 项目 | 操作 | 通过标准 | 实测值 / 结论 |
|---|---|---|---|
| 录音 | 接 `J_MIC`，录一段回放 | 有声音、无明显底噪 | |
| **L/R 声道** | 若录音是静音 | 板上 `J_MIC` 6 脚接的是 GND（左声道）。**静音就把模块的 L/R 改接 3V3 试右声道** | |
| 放音 | 接 `J_SPK` | 有声音、无破音。两根线都不接地 | |

### 5.3 I2C 外设与摄像头

| 项目 | 操作 | 通过标准 | 实测值 / 结论 |
|---|---|---|---|
| I2C 器件 | 读 status | PCA9685 / MPR121 / ADS1115 全部识别。**MPU6050 本批不贴，读不到是预期的** | |
| I2C 质量 | 跑 `tools/plush_toy_i2c_trial.py` | 丢帧率不劣于面包板基线。**这是验证这块板值不值得做的核心指标** | |
| 摄像头 | 接 `J_CAM` | 识别 OV3660，连续采集无持续掉帧 | |
| 触摸 | 接 `J_TOUCH`，摸电极 | 有响应 | |

### 5.4 调试口与待机

| 项目 | 操作 | 通过标准 | 实测值 / 结论 |
|---|---|---|---|
| J_EXT 取电 | 量 1 脚对 5 脚 | 3.3V | |
| J_EXT 串口 | 2 脚接 USB-TTL 的 RX | 能看到日志（**只出不进，板上没有 RX**） | |
| 外接复位 | 3 脚对 5 脚短接一下 | 板子复位 | |
| 外接功能键 | 4 脚对 5 脚短接一下 | 等效按板载 BOOT 键 | |
| 长按待机 | 长按功能键 2 秒，再长按退出 | 眼睛熄灭、停止说话、手臂泄力、加热断开；待机中摸头和晃动都不响应；退出后全部恢复 | |

## 七、加热（最危险，放最后）

> **门禁：第六节全部通过之前，不接加热。**
> **必须串 KSD9700 65℃ 常闭**（丝印已标）。2026-09-13 事故就是加热回路误接到开发板供电。

| 项目 | 操作 | 通过标准 | 实测值 / 结论 |
|---|---|---|---|
| 假负载 | **先接 5Ω / 10W 电阻，不接加热膜** | MOSFET 受控通断；`TP_GATE` 电平跟随指令 | |
| NTC 读数 | 接 `J_NTC`，与室温比对 | 读数合理，随手捏升温 | |
| 真加热膜 | 确认串了 KSD9700 后再接 | 升温可控，到目标温度停止 | |
| 保护动作 | **在主力板上做**，但必须先通过上面的假负载一项 | KSD9700 动作断开；固件进 fault 态。KSD9700 串在加热膜外面，动作时断的是加热回路，不伤板子 | |

## 九、卡住时先查什么

| 现象 | 先查 |
|---|---|
| 插上 USB 电流表读数为 0 | USB 线是否只有充电线芯；`F_USB` 保险丝是否断 |
| 电流持续攀升 / eFuse 反复动作 | 立即拔线。查 `TP_VBUS` 对地是否短路，重点看 SH 座和 USB-C 的连锡 |
| 3V3 为 0 | `U_BUCK` 焊接、`R_BUCK_EN` 是否虚焊 |
| 不枚举、烧不进 | 换一根**数据线**；按住 BOOT 再插；查 USB-C 的 D+/D- 与 CC 电阻 |
| 日志乱码 | 确认没有东西占用 GPIO43（控制台 TX） |
| 一只眼不亮 | 对调两只眼的线：跟着屏走是屏坏，留在原位是板子的 CS 线 |
| 背光常亮关不掉 | `R_LCD_BL_OFF` 或 `R_LCD_BL_GATE` 虚焊；`DISPLAY_BACKLIGHT_OUTPUT_INVERT` 极性 |
| 录音静音 | 先试 L/R 改接 3V3（右声道）；再查 `J_MIC` 连锡 |
| I2C 全部读不到 | `TP_SDA`/`TP_SCL` 对 3V3 应约 4.7kΩ；查 PCA9685 供电 |
| 上电即 BROWNOUT | 断开 VMOT 单独测逻辑域；确认两路电源真的独立 |

**任何一步出现冒烟、烫手、异味 —— 立即断电，不要"再试一次"。**
