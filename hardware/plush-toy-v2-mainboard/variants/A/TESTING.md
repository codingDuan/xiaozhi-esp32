# 二期版本 A 首板验收

版本 A：不带摄像头 · 单面贴片 · 52×46mm · 锂电池供电。

本清单在 DRC、未连接项、原理图一致性均为零问题后执行。静态检查不能代替实物测试；
每项都应记录**日期、板号、实测值和结论**。接线针序与外购件见 [WIRING.md](WIRING.md)。

**固件**：第四节「烧录」以后的项目需要 `plush-toy-v2` 固件（I2C 在 GPIO43/44、IMU 地址 0x19、
开机后经 I2C 关掉 IP5306 的轻载关机）。**一期固件不能用在这块板上**：引脚不同，而且不会关轻载关机，
电池供电时约 30 秒就会被断电。固件没好之前，只做第三节和第四节的前四项。

## 〇、仪器与两条一期教训

现有仪器：万用表（自动量程）、POWER-Z USB 电压电流表、红外测温枪、烙铁。

| 原本需要 | 降级做法 | 能证明 | **不能**证明 |
|---|---|---|---|
| 限流电源 | POWER-Z + 充电头 | 有无短路、静态电流是否离谱 | 上电瞬间的浪涌 |
| 示波器（SPI） | 看屏有无花点 | 链路基本可用 | 信号裕量 |
| 示波器（电源纹波） | 看日志有无 BROWNOUT / 异常复位 | 没掉到复位门限以下 | 纹波是否影响麦克风底噪、ADC 读数 |
| 热像仪 | 红外测温枪 | 热点位置与大致温度 | 小封装真实结温 |
| 电池内阻 / 容量仪 | 满电跑到关机计时 | 续航够不够 | 电池本身的健康度 |

**教训一：万用表先做对照再读数。** 每次换档后先做两下：**表笔悬空**（记下开路时屏幕显示什么）、
**表笔碰在一起**（约 0.2Ω）。2026-10-03 曾把开路的 `OL` 读成「0Ω 短路」，白查一大圈。

**教训二：通电时只点测试点。** 一期 #1 通电时用表笔点细间距引脚，板子最后报废。
本板背面有 8 个测试点（丝印即名字）：`TP_VUSB` `TP_VSYS` `TP_VBAT` `TP_3V3` `TP_GND` `TP_CC` `TP_EN` `TP_BOOT`。
通电状态下**只碰这 8 个**；要量别处，先断电。

**板号**：两块板用记号笔标 #1 / #2，收到固件后记下各自的 MAC。

## 三、不通电检查（万用表，不插电、不接电池）

**每项两块板都量**，#1 和 #2 读数差得多的就是可疑点。红笔接被测点、黑笔接 `TP_GND`（另有说明的除外）。

| 项目 | 操作 | 通过标准 | 实测值 / 结论 |
|---|---|---|---|
| 电源短路 | `TP_VUSB`、`TP_VSYS`、`TP_VBAT`、`TP_3V3` 各对 `TP_GND` | 均不为 0Ω（一般在几十 kΩ 到几 MΩ）。**任何一路为 0Ω 就停下** | |
| CC 分压 | `TP_CC` 对 `TP_GND` | 约 52kΩ（两路 100k + 5.1k 并联） | |
| EN / BOOT 上拉 | `TP_EN` 对 `TP_3V3`、`TP_BOOT` 对 `TP_3V3` | 各约 10kΩ | |
| 防反接旁路 | `J_BAT` 1 脚（丝印 +）对 `TP_VBAT` | 约 10kΩ（`R_BATP_BYP`）。**开路说明旁路电阻虚焊**：电池过放后将充不进电 | |
| 背光默认关断 | 红笔 `TP_3V3`、黑笔 `Q_LCD_BL` 的 1 脚（栅极） | 约 100kΩ。开路说明 `R_LCD_BL_OFF` 虚焊，上电会直接点亮背光 | |
| 舵机座 | `J_ARM_L` / `J_ARM_R` 的 5V 脚对 G 脚 | 不为 0Ω | |
| 加热座 | `J_HEAT` 两脚之间 | 不为 0Ω。**接近 0Ω 说明 `Q_HEAT` 击穿，上电即加热** | |

## 七、加热（最危险，放最后）

> **门禁：第六节全部通过之前，不接加热。**
> **必须串 KSD9700 65℃ 常闭**（丝印已标）。2026-09-13 事故就是加热回路接错。
> 加热只吃 USB 5V；**只有固件判定为 3A 电源时才会开**。

| 项目 | 操作 | 通过标准 | 实测值 / 结论 |
|---|---|---|---|
| NTC 读数 | 接 `J_NTC`，与室温比对 | 读数合理，手捏升温 | |
| **CC 判断：电脑口** | 插电脑，命令加热 | `TP_CC` 约 0.2V，**拒绝加热** | |
| **CC 判断：A 转 C 充电头** | 普通 USB-A 充电头 + A 转 C 线，命令加热 | 判为非 3A，**拒绝加热** | |
| **CC 判断：3A C-C 充电头** | 5V/3A C-C 充电头，命令加热 | `TP_CC` 约 0.84V，**允许加热** | |
| 假负载 | 3A 充电头下，`J_HEAT` 先接 5Ω / 10W 电阻 | 受控通断；POWER-Z 电流随指令跳约 1A | |
| 真加热膜 | 确认串了 KSD9700 后再接 | 升温可控，到目标温度停止 | |
| **边加热边充电** | 3A 充电头，电池未满，加热 + 充电 + 对话同时 **10 分钟** | 无复位，eFuse 不动作，POWER-Z 总电流 ≤ 3A（固件已调低充电电流） | |
| 拔 USB | 加热中拔掉 USB | 加热回路断电，系统转电池继续运行不复位 | |
| **模拟超温** | 用手 / 热风（远距离）把电池 NTC 或加热 NTC 读数抬过门限，或在固件里临时调低门限 | 停止加热；电池超温时同时关闭充电 | |
| 保护动作 | 加热膜持续加热到 KSD9700 动作 | KSD9700 断开；固件进 fault 态 | |

## 九、卡住时先查什么

| 现象 | 先查 |
|---|---|
| 插 USB 读数为 0 | 线是否只有充电线芯；`F_USB` 是否断 |
| 电流跳到 2A 附近 / 反复断开 | 立即拔线。断电后量 `TP_VUSB`、`TP_VSYS` 对地是否短路，重点看 USB-C 与 SH 座连锡 |
| `TP_VSYS` 为 0（有 USB） | `U_EFUSE` 输出（`TP_VUSB`）有没有；`U_CHG` 焊接，EP 散热焊盘是否虚焊 |
| 3V3 为 0 | `TP_VSYS` 有没有；`U_BUCK` 焊接 |
| 电池供电约 30 秒自己断电 | 固件没关 IP5306 轻载关机（寄存器 `0x00` bit1）；I2C 是否扫到 0x75 |
| 接电池按键不开机 | 电池线极性；`J_BAT` 1 脚对 `TP_VBAT` 是否约 10kΩ；`Q_BATN` / `Q_BATP` 焊接 |
| 充不进电 | 电池保护板是否已切断（量电池两端）；等几分钟涓流；`R_BATP_BYP` |
| 不枚举、烧不进 | 换**数据线**；按住 BOOT 再按 RST；查 USB-C 的 D+/D- 与 CC 电阻 |
| 一只眼不亮 | 对调 Y 型线两头：跟着屏走是屏坏，留在原位是 Y 型线那一支断了 |
| 背光常亮关不掉 | `R_LCD_BL_OFF` 或 `R_LCD_BL_GATE` 虚焊；固件背光极性 |
| 录音静音 | 模块 L/R 改接 3V3 试右声道；`J_MIC` 连锡 |
| I2C 全读不到 | 断电后量 `R_SCL` / `R_SDA` 两端约 4.7kΩ；GPIO43/44 有没有被串口日志占用 |
| 有 3A 头也不让加热 | `TP_CC` 读数；换一根 C-C 线（部分线没接 CC） |
| 上电即 BROWNOUT | 断开舵机与加热单独测；电池电量 |

**任何一步出现冒烟、烫手、异味 —— 立即断电，拔电池，不要「再试一次」。**

## 十、静态门槛

```sh
cd hardware/plush-toy-v2-mainboard/scripts
python3 -m unittest test_parts_db test_gpio test_core test_variants test_netlist test_export -v
```
