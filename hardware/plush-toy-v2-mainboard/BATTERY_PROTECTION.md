# 电池防反接方案

**状态**：待委托方确认（计划 Task 2）。确认前不进入 Task 4。

首板验收时必须实测「过放后首次充电」一行：用一块放空的电池插 USB，确认能充进电。

## 要求（spec 3.3）

PH2.0 电池线各家极性不一。电池接反时**任何器件不损坏，包括同时插着 USB 的情况**。

## 为什么难

IP5306 的 BAT 脚既是充电输出也是升压输入，电流双向、最大约 2.5A（双舵机同时动作时放电峰值）。
插着 USB 时，充电器会主动把电池节点拉到约 4.2V。**任何用「电池节点对地电压」去开关保护管的电路，都会被充电器骗开。**

下面用：`P1` = 电池座 1 脚（标「+」），`P2` = 电池座 2 脚（标「−」），`VBAT` = IP5306 的 BAT 脚节点，电池电压 3.7V。

## 候选方案

### A. 高边 P-MOS，栅极接地（最常见）

```
P1 ──┤ Q (P-MOS，漏极 P1，源极 VBAT)├── VBAT ── IP5306
           栅极 ── GND        P2 ── GND
```

| 工况 | 结果 |
|---|---|
| 正接，无 USB | 体二极管先导通，Vgs ≈ −3.7V，管子打开 ✅ |
| 正接，插 USB | 管子开，双向通流 ✅ |
| 反接，无 USB | P1 = −3.7V，体二极管反偏；源极悬空，Vgs ≈ 0，关断 ✅ |
| **反接，插 USB** | 充电器把源极拉到 4.2V，**Vgs = −4.2V，管子被打开**，4.2V 直接接到 −3.7V 的电池负端，回路电压 7.9V ❌ |

**否决**：不满足「插着 USB 时反接不损坏」。

### B. 低边 N-MOS，栅极接电池正端

把保护管放在负极回路里，栅极接 P1。

| 工况 | 结果 |
|---|---|
| **反接，插 USB** | 充电器把 P1（= VBAT）拉到 4.2V，**Vgs = 4.2V，管子被打开**，反接电池与充电器串联 ❌ |
| 管子换个方向（源极接 P2 让 Vgs 等于电池电压） | 反接无 USB 时，电流经体二极管 → GND → IP5306 衬底二极管 → VBAT 形成回路 ❌ |

**否决**：两种接法各在一种工况下失效。

### C. 高边 P-MOS + 一颗 N-MOS 直接读电池两端电压（推荐）

关键：**让开关保护管的决定只取决于电池两端的电压（P1 − P2），与充电器无关。**

```
                         R1 1M  
              ┌──────────/\/\/──────────┐
              │                         │
VBAT ─────────┴─ S ┤ Q1 P-MOS ├ D ──────┼──── P1（电池 +）
（IP5306 BAT）      │ G                  │
                   └──────┬─────────────┘
                          │
                          D
                     ┤ Q2 N-MOS ├
                          S ─── GND       P1 ──/\/\/── Q2 栅极 ──/\/\/── GND
                                           R2 100k             R3 1M
P2（电池 −）── GND
```

- **Q1**（AO3401A，P-MOS，C15127，基础库）：源极接 VBAT，漏极接 P1。体二极管方向是 P1 → VBAT。
- **R1**（1MΩ）：Q1 栅极上拉到源极，默认关断。
- **Q2**（AO3400A，N-MOS，C20917，基础库）：漏极接 Q1 栅极，源极接 GND。打开时把 Q1 栅极拉低，Q1 打开。
- **R4**（10kΩ，图中未画）：并在 Q1 漏源之间（VBAT ↔ P1）。见下表「过放后首次充电」一行。
- **R2**（100kΩ）+ **R3**（1MΩ）：Q2 栅极经 R2 接 P1、经 R3 接地。**Q2 的 Vgs 就是 P1 相对 P2 的电压**（P2 就是 GND），只有电池正接时才为正。

| 工况 | Q2 | Q1 | 结果 |
|---|---|---|---|
| 正接，无 USB | Vgs ≈ 3.7 × 1/1.1 = 3.36V，开（电池 3.0V 时 2.7V，仍高于 AO3400A 最大阈值 1.45V） | 体二极管先导通，随后栅极被拉低，Vgs ≈ −3.7V，开 | 双向通流 ✅ |
| 正接，插 USB | 开 | 开 | 充电与放电都走 Q1 沟道 ✅ |
| 反接，无 USB | Vgs = −3.36V，关（AO3400A 栅压额定 ±12V） | 栅极经 R1 等于源极，关；体二极管 P1(−3.7V) → VBAT 反偏 | 无回路，无电流 ✅ |
| **反接，插 USB** | Vgs = −3.36V，关 | VBAT = 4.2V，栅极经 R1 也是 4.2V，Vgs = 0，关；体二极管承受 7.9V 反压（AO3401A 额定 30V） | 只有 R4 漏过 (4.2 + 3.7) / 10k ≈ 0.8mA，6mW，无损坏 ✅ |
| 反接，无 USB（含 R4） | 关 | 关 | P1 → R4 → VBAT → IP5306 内部二极管 → GND 一路约 0.3mA，无损坏 ✅ |
| **正接，电池过放后被保护板切断，插 USB 充电** | 插头两端约 0V 时关；R4 把 P1 抬到约 2.5V 后开 | 随 Q2 打开 | 没有 R4 时充电器的电送不到电池，保护板永远不恢复，电池报废；有 R4 时先经 R4 涓流，保护板恢复后转入正常充电 ✅ |

**代价**

| 项 | 数值 |
|---|---|
| 新增器件 | 2 颗 SOT-23 + 4 颗 0402 电阻，**全部是基础库**，不增加换料费 |
| 导通压降 | AO3401A 在 Vgs = −3.7V 时约 65mΩ。平时约 0.3A → 20mV；双舵机峰值 2.5A → 0.16V、0.4W（持续数秒，SOT-23 额定 1.4W） |
| 对续航的影响 | 平均 0.9W ÷ 3.7V ≈ 0.25A → 4mW，约占 0.5%，可忽略 |
| 静态电流 | R1 支路 3.7V / 1M ≈ 3.7µA；R2+R3 支路 3.7V / 1.1M ≈ 3.4µA；合计约 7µA。用 2.2M/4.7M 可降到 2.4µA，但这两个阻值是扩展库，每种每单多一笔换料费，不值 |
| 关机总漏电 | IP5306 典型 50µA + 7µA ≈ 57µA，比 spec 3.3 的 50µA 上限多 7µA（约每月多 5mAh；1500mAh 电池放置约 2.4 年耗尽），可接受 |

### D. 电池两端并一颗反向二极管 + 串联自恢复保险丝

反接时二极管把电池短路，靠电池保护板或保险丝切断。

**否决**：依赖电池自带保护板动作；二极管在 3.7V 下的漏电流（肖特基几十 µA）会吃掉关机电流预算；短路瞬间 IP5306 的 BAT 脚被拉到 −0.5V 以下，超过其绝对最大额定值。

## 结论

采用 **方案 C**。实施时（Task 4）：
- 不新增 `parts_db` 条目：Q1、Q2 复用 `AO3401A`、`AO3400A`，电阻用基础库 0402。
- 位号：`Q_BATP`（Q1）、`Q_BATN`（Q2）、`R_BATP_PU`（R1）、`R_BATN_G`（R2）、`R_BATN_PD`（R3）、`R_BATP_BYP`（R4）。
- 网络：`VBAT_PACK`（P1）、`VBAT`（IP5306 BAT）、`BATP_GATE`（Q1 栅极）、`BATN_GATE`（Q2 栅极）。
- 电阻全部用已有基础库料号：1M（C26083）、100k（C25741）、10k（C25744）。
- 测试：`VBAT_PACK` 与 `VBAT` 之间只有 `Q_BATP` 与 10k 的 `R_BATP_BYP`；`Q_BATN` 的栅极只经电阻接到 `VBAT_PACK` 与 `GND`，不接 `VBAT`（防止被充电器骗开）。
