## 1. 为什么要做二期

一期板（90×60mm）的任务是把面包板电路搬上 PCB，验证电路本身。一期首板已验证屏、麦克风、喇叭、触摸、舵机电路可用（见 `hardware/plush-toy-mainboard/TESTING.md`）。二期朝**可装进玩偶的成品形态**走：

| 一期的问题 | 二期目标 |
|---|---|
| 90×60mm，约为成品机芯的 2.3 倍 | **尽量小**，委托方期望面积约为一期的 30%（见第 10 节） |
| 9 个接线座不在贴片清单里，要手焊 | **零手焊**：全部贴片座，工厂贴好 |
| 只能 USB 带线供电，舵机另接 5V 电源 | 内置锂电池，插 USB 充电；舵机从电池升压取电 |
| 两眼各一根 8 芯线，穿脖子粗硬 | 板上一个眼睛座，两眼共用片选 |
| 按键大，装进玩偶按不到 | 板上**小按键**（RST、BOOT），另引出电源键与收音键 |
| 成本：MPU-6050 一颗 ¥130，多颗进口芯片 | **成本是关键指标**，见第 9 节 |

**不变的**：ESP32-S3-WROOM-1-N16R8 模组（资源分区需要 16MB Flash）；加热膜必须串 KSD9700；加热回路栅极下拉必贴。

## 3. 一期验收带来的事实

二期设计以这些实测为准，不再按假设设计：

| 实测 | 数值 | 对二期的意义 |
|---|---|---|
| 无屏、Wi-Fi 热点开启时整机电流 | 85mA @5V | 待机功耗基线 |
| 双眼点亮（背光 75%） | 130mA @5V，单眼背光约 25mA | **这款屏模块自带背光限流**，板上背光开关可以不串限流电阻。换屏要重测 |
| 双眼 SPI 40MHz、约 10cm 杜邦线 | 6 种主题轮换无花屏 | Y 型线共片选后仍需实测（线更长、两个负载并联） |
| 不按 BOOT 能否烧录 | 能，USB 自动进下载模式 | BOOT 键只作功能键用 |
| 摇晃 / 翻转检测 | 固件只读加速度，不用陀螺仪 | MPU-6050 可换成纯加速度计 |
| 舵机由 VMOT 供电、双臂 hug/cheer/wave | 无复位 | 舵机电路可沿用 |
| 万用表读数 | 一度把开路误读为 0Ω | 二期测试点仍放背面，验收流程保留「先对照」步骤 |

**仍缺**：摄像头（一期未接时报 `0x106 not supported`，未实测）、对话时整机功耗、舵机峰值电流、加热。前一项决定第 10 节选哪个版本，后三项决定电池与升压选型。

## 4. 一期没考虑到、二期必须加的

| # | 项 | 做法 |
|---|---|---|
| 1 | 陀螺仪成本 | MPU-6050（10 片价 $18.09）换 **LIS2DH12**（$0.78，2×2mm）。固件 `MotionController` 只用加速度，需新写驱动 |
| 2 | 眼睛接线 | 屏模块只有一排 8 针、没有直通口，「串联」= Y 型分叉线。共片选后只要 8 根：RST、CS、DC、MOSI、CLK、BL、3V3、GND |
| 3 | 背光限流 | 设计文件写明「依赖屏模块自带限流，单眼实测 25mA」，换屏必须重测 |
| 4 | 电池插头极性 | PH2.0 电池线各家正负经常相反，**接反直接烧板**。板上加防反接（P-MOS），丝印大字标 +/−，并在采购清单指定电池卖家 |
| 5 | 电池温度 | 电池在毛绒里不透气。优先选带电池 NTC 脚的充电芯片；若选不带的（如 IP5306），电池旁加一颗 NTC 进 ADC，固件超温时停止加热并告警，且电池远离加热膜 |
| 6 | 关机耗电 | 关机后电池漏电要 < 50µA（一个月掉电 < 40mAh），选型时核对充电芯片关机电流 |
| 7 | 静电 | 触摸电极（导电布被人直接摸）、外接按键线加 ESD 管 |
| 8 | 板型身份 | 新建板型 `plush-toy-v2`，**不改** `plush-toy`。板型名影响 OTA，不能让一期板收到二期固件 |
| 9 | 固件改动清单 | 收音键、电池电量、USB 插入检测、加热仅 USB 时允许、LIS2DH12 驱动、共片选眼睛；不带摄像头版本另加：LEDC 舵机、片上 ADC 测温、片上触摸 |
| 10 | IP5306 类芯片轻载关机 | 这类充放电芯片输出电流低于约 45mA 持续约 30s 会自动关升压。待机关屏时整机可能低于此值而被断电。选型时必须核对，必要时选带 I2C 可关此功能的型号 |

## 5. 电源架构

```
USB-C 5V ──┬── 自恢复保险丝 ──► 充放电芯片 ◄──► 锂电池 1S（经防反接）
           │                        │
           │                        └─► 系统 5V ──┬── 功放
           │                                      ├── 舵机 ×2（贴片电容储能）
           │                                      └── 降压 → 3V3 ──┬── ESP32、屏、传感器
           │                                                      └── LDO 2.8V/1.5V（仅带摄像头版本）
           │
           └── 加热专用支路 ──► Q_HEAT ──► HEAT 座（板外串 KSD9700）
```

- **加热只接 USB 5V**，拔掉 USB 加热回路物理上无电。
- 一期的 VMOT 独立输入、KF301 螺丝端子、1000µF 电解电容、SMBJ 瞬态管、防反接 P-MOS 全部取消，舵机储能改用贴片电容。
- **保留 eFuse**（TPS259531，$0.72）。第二稿曾提议取消；2026-10-05 一期 #1 发生 3V3 短路，eFuse 把故障电流限在约 2A，证明值得保留。
- 逻辑地与舵机 / 加热回流仍按一期思路在入口附近单点汇合。

**USB 电流预算仍是最大的电源问题**：插 USB 时加热（约 1A）+ 充电 + 系统运行可能超过 2.5A，电脑 USB 口只给 0.5–0.9A。候选做法：规定加热时必须用 5V/3A 充电头；或固件检测到加热时请求降低充电电流（需带 I2C 的充电芯片）。

## 6. GPIO

一期 30 个可用 GPIO 已占 29 个（摄像头一项 14 个），只剩 GPIO43。

| 版本 | GPIO 情况 |
|---|---|
| **带摄像头** | 共片选释放 GPIO46，加上 GPIO43 共 2 个空脚。舵机、加热 PWM、触摸、ADC 仍需 I2C 芯片 |
| **不带摄像头** | 释放 14 个脚。舵机用 LEDC、测温 / 电池电压用片上 ADC、触摸用片上触摸通道，**PCA9685、ADS1115、MPR121 三颗芯片全部去掉** |

带摄像头版本还有一条省钱路：两个空脚给两路舵机（LEDC），加热栅极与收音键挂到 MPR121 的 GPIO 功能上，去掉 PCA9685（$2.53，**立创当前缺货**）。代价是固件改动，以及加热改由 MPR121 驱动——它复位时 GPIO 为输入，栅极下拉仍保证默认关断。

## 7A. 摄像头座方向：必须修掉（硬性要求）

一期 J_CAM 引脚顺序设计反了，接上摄像头一上电就把 +1V5 短到摄像头地，**已经报废一块板**（见 `hardware/plush-toy-mainboard/TESTING.md` 事故记录）。二期带摄像头的版本（C、D）必须同时满足下面五条，缺一条不下单：

1. **以实测为准，不再照抄参考设计的针表。** 一期实测：AFC01-S24FCA-00（下接）、本封装、排线触点朝下插入时，**摄像头第 k 脚落在板上第 25−k 脚**。二期若沿用同一座子与封装，焊盘 n 接摄像头第 25−n 脚的信号；若改用上接座 AFC01-S24FCC-00，需重新实测，不能推算。
2. **自动检查**：`board_spec.py` 中 J_CAM 的映射写成「焊盘号 → 摄像头脚号 → 信号」两级，测试断言摄像头的 DVDD、AVDD、DOVDD、AGND、DGND 落在预期焊盘上，并断言「摄像头电源脚不会落在 ESP32 GPIO 上」。改座子型号而没更新映射时测试失败。
3. **下单前实物核对**：用一期 #2（引脚已知是反的）或打印 1:1 封装图，配实物排线确认 1 脚落点与镜头朝向；结果写进 `WIRING.md` 并配照片。
4. **首板上电前不通电验证**：插上摄像头量「座子空脚对 +1V5」应为 OL，二极管档 +1V5→GND 方向不应比不接摄像头时明显变低。两项都过才允许上电。
5. **丝印**：座子旁画出排线插入方向与「触点朝下 / 朝上」字样。

可选（看面积与成本）：DVP 数据线串 22–33Ω 电阻，既改善信号边沿，也能在接错时限制灌进 ESP32 GPIO 的电流。

## 8. 板形与布局原则

1. **外形跟着盒子走**：圆角，螺丝孔放圆角里，用 M2 孔（一期 M3 占 49mm²/个）。
2. **出线座集中在一到两条边，开口同向**，盒子少开口。
3. **USB-C 卡在板边**，对准盒子开孔。
4. **天线伸出板边**，下方禁铜；天线一侧远离电池与喇叭磁铁。
5. 测试点全部放背面。
6. 两颗充电指示灯放在能透过盒子看到的位置。
7. **双面贴片版本**：正面放模组、连接器、按键（需要从正面插拔或按）；背面放电源、功放、传感器芯片与阻容。

## 10. 四个版本对比

### 10.1 估算方法

- 元件占地按一期 PCB 实测的封装外框面积，加上二期新增 / 替换件的封装尺寸；ESP32 模组按天线伸出板边计，板上部分约 18×20mm。
- 单面贴片按布局密度 55% 折算板面积（一期约 41%，成品机芯约 55–60%）。
- 双面贴片按「正反两面可用、密度 50%」折算；正面至少要放下模组、连接器和按键。
- **这是布局前的估算**，误差约 ±20%，实际以布局结果为准。

### 10.2 元件占地

| 类别 | 不带摄像头 | 带摄像头 |
|---|---|---|
| ESP32 模组（板上部分） | 360mm² | 360mm² |
| USB-C、充放电、降压、功放、加速度计、加热、ESD | 290mm² | 290mm² |
| 连接器 9 个 + 按键 2 个 | 430mm² | 430mm² |
| 阻容、指示灯、M2 孔 ×2 | 130mm² | 130mm² |
| 摄像头 FPC 座 + 2 颗 LDO | — | 130mm² |
| PCA9685 + ADS1115 + MPR121 及其阻容 | — | 150mm²（去掉 PCA9685 时约 70mm²） |
| **合计** | **约 1200mm²** | **约 1480mm²** |

### 10.3 结果

| 版本 | 估算尺寸 | 面积 / 一期 | 主要芯片成本 / 台 | 贴片费 | 难度 |
|---|---|---|---|---|---|
| **A. 不带摄像头 · 单面** | 约 52×42mm | **约 40%** | **最低**（$6.97） | 最低 | 低 |
| **B. 不带摄像头 · 双面** | 约 42×34mm | **约 26%** ✅ | $6.97 | 较高（双面需标准贴片，工程费、钢网翻倍） | 中 |
| **C. 带摄像头 · 单面** | 约 60×45mm | 约 50% | $12.86（去掉 PCA9685 为 $10.33） | 低 | 中 |
| **D. 带摄像头 · 双面** | 约 46×38mm | **约 32%** | $12.86（去掉 PCA9685 为 $10.33） | 较高 | 高 |

主要芯片成本 = 模组 $4.56 + LIS2DH12 + NS4168 + IP5306 + eFuse $0.72（+ 带摄像头时的 PCA9685、ADS1115、MPR121），按 9.1 节单价相加；作对比，一期同口径为 $11.61（未贴 MPU-6050）。不含阻容、连接器、PCB、摄像头模组本身与锂电池。

**只有 B、D 能达到或接近 30%。** 双面贴片的代价：嘉立创经济型贴片只做单面，双面要走标准型，工程费、钢网都多一套，10 台分摊后每台增加的费用以报价为准；双面板的返修与测试也更难。

### 10.4 建议

1. **先测一期的摄像头**。摄像头是否保留，决定在 A/B 与 C/D 之间选。
2. 不要摄像头 → **B**（面积 26%，芯片成本最低）。若双面贴片报价太高，退到 A（40%）。
3. 要摄像头 → **D**，并按第 6 节去掉 PCA9685（同时规避它的缺货）。

## 12. 风险

- **布局从头来**：一期全量重新生成布线不收敛（见 `hardware/plush-toy-mainboard/README.md`），二期更小更密，双面版本自动布线更难，可能需要更多人工干预。
- **电池安全**：必须用带保护板的电芯；加热膜与电池不能挨着；电池插头防反接。
- **天线**：板子越小地平面越小，加上电池、喇叭靠近，Wi-Fi 性能会变差，只能实测。
- **共片选 + Y 型线**：两屏并联、线更长，40MHz 可能不稳，需在一期板上先试。
- **全部重新验收**：二期是新板，按新板重写 TESTING.md。
