## 1. 为什么要做二期

一期板（90×60mm）的任务是把面包板电路搬上 PCB，验证电路本身。委托方拿它和拆解的成品机芯（涂鸦 T5-E1 模组）对比后，确定二期要朝**可装进玩偶的成品形态**走：

| 一期的问题 | 二期目标 |
|---|---|
| 面积约为成品 2.3 倍 | 按外壳收紧，目标约 70×50mm（摄像头保留，缩到一半不现实，见 2.1） |
| 9 个接线座不在贴片清单里，要手焊 | **零手焊**：工厂贴好，板上只剩不焊的调试孔 |
| 只能 USB 带线供电 | 内置锂电池，插 USB 充电 |
| 两眼各一根 8 芯线，穿脖子粗硬 | 一根线菊花链串两只眼睛 |
| 按键贴在板上，装进玩偶按不到 | 按键全部外接 |
| 座子散在四条边，丝印是位号 | 座子集中在出线一侧，丝印写功能名 |

**不变的**：功能全部保留；ESP32-S3-WROOM-1 模组；一期固件的 GPIO 分配（除 3.3 节列出的改动）；加热膜必须串 KSD9700 的规则。

### 2.1 为什么摄像头决定了面积

一期器件本体已占约 3600mm²，还没算走线。摄像头占 14 个 GPIO，拿掉它就能改用 ESP32 片上的 PWM / ADC / 触摸，PCA9685、ADS1115、MPR121 三颗芯片连带可省，那样才可能缩到一半。摄像头保留，这三颗芯片也都保留，面积只能靠第 5 节的布局办法省。

## 3. 电源架构

### 3.1 电源树

```
USB-C 5V ──┬── eFuse ──► 充电/升压芯片 ◄──► 锂电池 1S
           │                  │
           │                  └─► 系统 5V ──┬── 功放 MAX98357A
           │                                ├── 舵机 ×2（经大容量电容）
           │                                └── 降压 → 3V3 ──┬── ESP32、屏、传感器
           │                                                 └── LDO → 摄像头 2.8V / 1.5V
           │
           └── 加热专用支路（独立限流）──► Q_HEAT ──► J_HEAT（板外串 KSD9700）
```

- **加热只接在 USB 5V 上**。拔掉 USB，加热回路物理上无电。「电池时不加热」由硬件保证，不依赖固件。
- 舵机从电池升压后的系统 5V 取电。一期的 `VMOT` 独立输入、螺丝端子和 1000µF 电解电容取消。

### 3.2 一期硬约束如何继承

一期 HC-1「电机/加热与逻辑两个域没有任何铜连接」来自 2026-09-13 事故（加热接到了开发板供电，烧坏 LDO）。上电池后只有一个电源入口，这条不能原样保留，改为：

| 一期 | 二期 |
|---|---|
| 两个独立输入，正极无铜连接 | 加热支路在 eFuse 之后、充电芯片之前**单独分出**，有自己的限流，不经过降压和 LDO |
| PGND 与 GND 单点汇合 | 保留思路：舵机与加热的回流走独立铺铜，在电源入口附近单点汇入逻辑地 |
| 加热栅极 100kΩ 下拉必贴 | 不变 |

### 3.3 GPIO 变化

只动一个脚，其余与一期 `config.h` 相同：

| GPIO | 一期 | 二期 |
|---|---|---|
| 43 | UART TX，只引到测试点（控制台实际走 USB Serial/JTAG） | **收音键**，串 1kΩ（防止上电时 ROM 驱动此脚与按下的按键短路） |
| 0 | BOOT，板载按键 + J_EXT | 只引到调试孔。烧录靠 USB 自动进下载模式（一期首板已验证） |

### 3.4 电量与 USB 检测

ADS1115 一期只用了 AIN0（NTC），剩 3 路：

| 通道 | 二期用途 |
|---|---|
| AIN0 | NTC 测温（不变） |
| AIN1 | 电池电压，经分压（输入不能超过 VDD+0.3V） |
| AIN2 | USB 5V 是否插入，经分压。固件据此决定是否允许加热，并在界面上提示 |

不占 GPIO。

### 3.5 电源键

外接电源键接充电/升压芯片的按键脚（长按开关机），不经过 ESP32。选型时必须确认该芯片支持按键开关机。

## 5. 板形与布局原则

照成品机芯的做法：

1. **外形跟着盒子走**：圆角，螺丝孔放在圆角里，需要避让盒内结构的地方开缺口。
2. **出线的座子集中在一条边，开口朝同一方向**，盒子只开一个出线口。
3. **USB-C 卡在板边**，对准盒子开孔，同时负责充电和烧录。
4. **天线伸出板边**，下方和周围禁铜（同一期）。天线一侧远离电池和喇叭磁铁。
5. **单面贴片**。测试点放背面：背面只有焊盘，不增加贴片费用。
6. **丝印写功能名**（LCD、MIC、SPK、BAT…），字号大到组装时一眼能看清。
7. **两颗充电指示灯**（充电中 / 充满），放在能透过盒子看到的位置，或在盒上留导光孔。
8. 板上**不放按键**。复位用两个焊盘，镊子短接。

一期保留、成品没有的：**测试点**。二期仍是验证板，只有万用表时测试点是唯一的测量手段，挪到背面，不删。

### 7.2 选型与设计待定

| 项 | 要求 / 风险 |
|---|---|
| 充电/升压芯片 | 1S 充电 + 5V 升压 + 按键开关机 + 充电指示。舵机峰值约 1.4A（SG90 堵转 700mA×2），加上功放与系统，**升压输出按 ≥ 2.5A 峰值选**。注意部分此类芯片轻载会自动关机，待机时可能被误关，选型时必须核对 |
| USB 电流预算 | 插着 USB 时同时加热（约 1A）、充电（约 1A）、系统运行，合计可能超过 2.5A。电脑 USB 口只能给 0.5~0.9A。需要：充电芯片有输入限流，或加热时降低充电电流，或规定加热时必须用 5V/3A 充电头。**这是二期最大的电源设计问题** |
| 电池规格 | 容量待 7.1 实测；尺寸决定盒子厚度 |
| 按键功能分配 | 电源键、收音键之外，BOOT 原有的「单击对话 / 长按待机」要不要保留、放在哪个键上 |
| 舵机座料号 | 已定用 2.54mm 贴片排针 1×3，待查嘉立创有库存、带定位柱的具体料号 |
| 加热座型号 | ≥ 3A 的贴片座 |
| 板子尺寸 | 目标约 70×50mm，实际布局后才能确定 |

## 8. 风险

- **布局从头来**：一期全量重新生成布线不收敛（见 `hardware/plush-toy-mainboard/README.md`），二期面积更小、密度更高，自动布线更难，可能需要更多人工干预。
- **电池安全**：锂电池在毛绒玩具里，必须用带保护板的电芯，充电芯片要有过温保护。加热膜和电池不能挨着。
- **天线**：板子变小，地平面变小，加上电池和喇叭靠近，Wi-Fi 性能会变差，只能实测。
- **全部重新验收**：二期是新板，一期 TESTING.md 的验收要按新板重做。
