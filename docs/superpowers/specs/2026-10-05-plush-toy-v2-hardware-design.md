**日期**：2026-10-05

## 1. 目标与成功标准

**目标**：一块可装进玩偶外壳的主板，零手焊、内置锂电池、尽量小、尽量便宜，四个版本对比。

**成功标准**（每个打样版本都要满足）：

1. 工厂贴片完成后**无需任何手焊**即可组装：所有元件 `assembly=True` 且有立创料号。
2. 眼睛、语音（麦克风 + 喇叭）、双臂舵机、头部触摸、加速度计、加热（仅插 USB 时）全部可用。
3. 电池供电下**不加热、连续对话 ≥ 4 小时**；待机 5 分钟不被充放电芯片自动断电。
4. 插电脑 USB、普通充电头、5V/3A 充电头三种情况下都不反复重启；只有电源报告 3A 时才允许加热。
5. 带摄像头版本：第 7 节五条全部满足后才允许接摄像头上电。

## 2. 四个版本

一套核心电路 + 一个可选摄像头模块，四份布局：

| 版本 | 摄像头 | 贴片 | 估算尺寸 | 面积 / 一期 | 主要芯片成本 |
|---|---|---|---|---|---|
| **A** | 无 | 单面 | 约 52×42mm | 约 40% | 约 $7.6 |
| **B** | 无 | 双面 | 约 42×34mm | 约 26% | 约 $7.6 |
| **C** | 有 | 单面 | 约 60×45mm | 约 50% | 约 $11 |
| **D** | 有 | 双面 | 约 46×38mm | 约 32% | 约 $11 |

尺寸为布局前估算（±20%），以实际布局为准。芯片成本 = 模组 + 充放电 + 功放（MAX98357A，2026-10-05 修订后 +$0.55）+ 加速度计 + eFuse（+ 带摄像头时 MPR121、ADS1115），立创 10 片价，不含阻容、连接器、PCB 与贴片费。

**画板顺序 A → B → C → D**。A 画完后给委托方看实际尺寸与报价，再决定是否继续 B/C/D。

## 3. 电源

```
USB-C ──┬─ 自恢复保险丝 ─ eFuse ─┬─► IP5306-I2C ◄──► 锂电池 1S 1500mAh（防反接）
        │                       │        │
        │  CC1/CC2 ─► 分压 ─► ADC │        └─► 系统 5V ─┬─ 功放 MAX98357A
        │                       │                     ├─ 舵机 ×2（贴片电容储能）
        │                       │                     └─ 降压 SY8089 ─► 3V3 ─ ESP32、眼睛、传感器
        │                       │                                       └─（C/D）LDO 2.8V / 1.5V
        │                       └─► 加热支路 ─► Q_HEAT ─► HEAT 座（板外串 KSD9700）
```

### 3.1 已定选型与依据

| 项 | 决定 | 依据 |
|---|---|---|
| 充放电 + 升压 | **IP5306-I2C**（单芯片：1S 充电、5V 升压、按键开关机） | 原版 IP5306 输出低于约 45mA 持续约 30s 会自动关升压；一期实测待机仅 40mA@5V（0.2W），会被断电。I2C 版本由 ESP32 开机后关闭此功能 |
| 电池 | 1S 锂聚合物 **1500mAh**，带保护板 | 实测对话 0.54W（无屏）+ 双眼 0.23W + 舵机均摊约 0.1W ≈ 0.9W；计转换效率 85%、4h ≈ 4.2Wh ≈ 1150mAh，留 30% 余量 |
| USB 保护 | 保留自恢复保险丝 + **eFuse TPS259531** | 一期 #1 事故中 eFuse 把故障电流限在约 2A |
| 3V3 | SY8089 降压（同一期） | 一期已验证 |
| 一期 VMOT 输入整套 | **取消**（螺丝端子、1000µF、SMBJ、Q_REV） | 舵机改由系统 5V 供电 |

### 3.2 加热与 USB 电流预算

- 加热**只接 USB 5V**（eFuse 之后、IP5306 之前分出），拔掉 USB 加热回路物理上无电。
- **CC 判断电源能力**：CC1、CC2 各经 100kΩ 汇到一个 ADC 节点（未连接的一路约 0V，节点电压约为有效 CC 电压的一半）。对应关系：默认电流约 0.2V、1.5A 约 0.45V、3A 约 0.84V。**只有判定为 3A 时固件才允许加热**。用 A 转 C 线时只会报默认电流，不加热（有意保守）。
- **加热期间经 I2C 调低 IP5306 充电电流**，使加热 + 充电 + 系统 ≤ 3A。
- 加热栅极 100kΩ 下拉必贴（同一期）。

### 3.3 电池安全

- **防反接**：PH2.0 电池线各家极性不一。要求：电池反接时任何器件不损坏，**包括同时插着 USB 的情况**。2026-10-05 定稿为「高边 P-MOS + 读电池两端电压的 N-MOS + 10k 旁路」，见 `hardware/plush-toy-v2-mainboard/BATTERY_PROTECTION.md`（委托方已确认）。
- **电池测温**：IP5306 没有电池 NTC 脚。电池旁放一颗 10k NTC 进 ADC；超温时固件停止加热，并经 I2C 关闭充电（以芯片手册寄存器为准，选型时确认）。
- 加热膜、IP5306、降压芯片布置在远离电池的一侧。
- 关机后电池漏电 < 50µA（选型时核对 IP5306 关机电流）。

## 4. 接口与连接器

全部贴片，全部进 BOM。出线座集中在一到两条边、开口同向。丝印写功能名。

| 丝印 | 接什么 | 座子 | 针 | 备注 |
|---|---|---|---|---|
| USB | 充电 + 烧录 | USB-C 16P（选比一期 HRO TYPE-C-31-M-12 小的型号） | — | 卡板边 |
| BAT | 锂电池 | PH2.0 2P 卧贴 | 2 | 防反接，丝印大字 +/− |
| LCD | 双眼，共片选 | SH1.0 8P 卧贴 | 8 | RST、CS、DC、MOSI、CLK、BL、3V3、GND；头部用 Y 型线分两屏 |
| MIC | I2S 麦克风 | SH1.0 6P | 6 | 针序同一期 J_MIC，一期线可复用 |
| SPK | 喇叭 | SH1.0 2P | 2 | 2026-10-05 修订：原 MX1.25，统一为与 NTC、TOUCH 相同的座子 |
| ARM L / ARM R | 舵机 ×2 | 2.54mm 贴片排针 1×3（带定位柱） | 3 | 信号 / 5V / GND，舵机原插头直插 |
| HEAT | 加热膜 | XH2.54 2P 卧贴，额定 3A | 2 | |
| NTC | 加热测温 | SH1.0 2P | 2 | 与 HEAT 分开 |
| TOUCH | 头部触摸 | SH1.0 2P | 2 | ESD 管 |
| KEY | 电源键 + 收音键 | SH1.0 3P | 3 | PWR（接 IP5306 按键脚）、MUTE、GND；ESD 管 |
| CAM | 摄像头（C/D） | AFC01-S24FCA-00 | 24 | 见第 7 节 |

板上另有：RST、BOOT 两颗 3×4mm 贴片按键；背面测试点（3V3、5V、VBAT、GND、EN、BOOT、CC 汇总点）；2 个 M2 安装孔。

**充电指示**（2026-10-05 修订）：IP5306-I2C 把 LED 脚改作 I2C，没有指示灯驱动。取消两颗指示灯，由固件经 I2C 读充电 / 充满状态，在眼睛屏上显示。

**眼睛不串限流电阻**：依赖屏模块自带背光限流（一期实测单眼约 25mA）。换屏型号必须重测。

## 5. GPIO 与总线（固件接口约定）

ESP32-S3-WROOM-1-N16R8 可用 GPIO 共 31 个：0–18、21、38–48（35–37 被八线 PSRAM 占用，19/20 为 USB）。

### 5.1 四个版本相同的部分

| 功能 | GPIO | 说明 |
|---|---|---|
| BOOT 键 | 0 | 板上按键 |
| 眼睛 CLK / MOSI / DC / CS / RST / BL | 38 / 14 / 47 / 45 / 21 / 48 | 同一期，去掉右眼 CS（GPIO46） |
| 麦克风 WS / SCK / DIN | 1 / 2 / 42 | 同一期 |
| 功放 DOUT / BCLK / LRCK | 39 / 40 / 41 | 同一期（2026-10-05 修订：NS4168 输入门限 0.7×VDD 与 3.3V 逻辑不兼容，改回 MAX98357A） |
| I2C SCL / SDA | **43 / 44** | 一期 SCL 在 GPIO3。改到 43：启动时 ROM 在 43（UART0 TX）上的输出只动 SCL，SDA 保持高，不构成 I2C 起始条件 |
| 舵机 L / R | **3 / 46** | LEDC 直接输出。46 为启动配置脚，加 10k 下拉；3 在未烧 JTAG 选择 eFuse 时不影响启动 |

I2C 总线上：IP5306-I2C、LIS2DH12（四个版本都有）。

### 5.2 不带摄像头（A/B）

| 功能 | GPIO / 外设 |
|---|---|
| 加热栅极 | GPIO17 |
| 收音键 | GPIO18 |
| 头部触摸 | GPIO8（片上触摸通道） |
| 加热 NTC / 电池电压 / CC / 电池 NTC | GPIO4 / 5 / 6 / 7（ADC1，Wi-Fi 工作时可用） |

空余：9–13、15、16。

### 5.3 带摄像头（C/D）

| 功能 | GPIO / 外设 |
|---|---|
| 摄像头 SIOD / SIOC / VSYNC / HREF / XCLK / PCLK | 4 / 5 / 6 / 7 / 15 / 13 |
| 摄像头 D0–D7 | 11 / 9 / 8 / 10 / 12 / 18 / 17 / 16（同一期） |
| 加热栅极、收音键 | MPR121 的 GPIO 功能（复位后为输入，栅极下拉保证默认关断） |
| 头部触摸 | MPR121 ELE0 |
| 加热 NTC / 电池电压 / CC / 电池 NTC | ADS1115 AIN0 / AIN1 / AIN2 / AIN3 |

31 个 GPIO 全部用满。I2C 上另有 MPR121、ADS1115。PCA9685 不用（立创 2026-10-04 缺货）。

## 6. 布局与制造

- **四层板**，1.6mm。圆角矩形，M2 孔在圆角。外壳按板子做。
- **天线伸出板边**，下方及周围禁铜；电池、喇叭磁铁远离天线一侧。
- **双面版本（B/D）**：正面放模组、全部连接器、按键、指示灯；背面放电源、功放、传感器芯片与阻容。嘉立创需走标准型贴片。
- 尺寸由布局迭代决定：按估算面积起步，逐轮收缩至无法再收。
- 阻容尽量用嘉立创基础库，报告扩展库种类数。

## 7. 摄像头座方向（硬性要求，C/D）

一期 J_CAM 引脚顺序设计反了，接上即把 +1V5 短到摄像头地，已报废一块板（见 `hardware/plush-toy-mainboard/TESTING.md` 事故记录）。五条缺一不可：

1. **以实测为准**：一期实测 AFC01-S24FCA-00（下接）+ 本封装 + 排线触点朝下时，**摄像头第 k 脚落在焊盘第 25−k 脚**。二期沿用同一座子与封装，焊盘 n 接摄像头第 25−n 脚的信号。换座子型号必须重新实测，不得推算。
2. **自动检查**：`board_spec` 中 J_CAM 写成「焊盘号 → 摄像头脚号 → 信号」两级映射，测试断言 DVDD、AVDD、DOVDD、AGND、DGND 落在预期焊盘，且摄像头任何电源脚都不落在 ESP32 GPIO 上。
3. **下单前实物核对**：用一期 #2 或 1:1 打印封装图配实物排线，确认 1 脚落点与镜头朝向，结果与照片写进 `WIRING.md`。
4. **首板上电前不通电验证**：插上摄像头，「座子空脚对 +1V5」应为 OL；二极管档 +1V5→GND 方向不应比不接摄像头时明显变低。
5. **丝印**画出排线插入方向与触点朝向。

## 8. 画板流程与自动检查

- 新目录 `hardware/plush-toy-v2-mainboard`。沿用一期脚本流程：电路描述 → 原理图 → 布局 → 扇出 → Freerouting → 布线后修补 → DRC → 导出生产文件。
- **一份核心电路描述 + 四个版本的差异描述**（摄像头模块、单 / 双面放置）。
- 一期测试全部沿用（DRC、原理图一致性、BOM 料号等），新增：
  1. 每个版本：除测试点与安装孔外，所有元件 `assembly=True` 且有立创料号。
  2. 每个版本：GPIO 无冲突，且与第 5 节表格一致。
  3. C/D：第 7 节第 2 条的摄像头映射断言。
  4. 下单前：嘉立创库存检查 + 扩展库种类数报告。
- 每个版本输出：Gerber、BOM、坐标、`WIRING.md`（含采购清单）、`TESTING.md`（验收清单）。

**风险**：一期全量重新布线不收敛；二期更小更密，双面更难，需要较多人工修补，画板周期长于一期。

## 9. 验收要点（写入各版本 TESTING.md）

沿用一期 TESTING.md 的分段与门禁（不通电 → 首次上电 → 外设逐个加 → 加热最后），新增：

| 项 | 通过标准 |
|---|---|
| 待机不断电 | 电池供电、屏熄灭待机 5 分钟，系统不被 IP5306 关断 |
| CC 判断 | 电脑口、A 转 C 普通充电头：判定为非 3A，拒绝加热；5V/3A C-C 充电头：允许加热 |
| 边加热边充电 | 3A 充电头下加热 + 充电 + 对话同时进行 10 分钟，无复位、eFuse 不动作 |
| 续航 | 满电、不加热、连续对话 ≥ 4 小时 |
| 电池测温 | 加热 NTC 与电池 NTC 读数合理；模拟超温时停止加热与充电 |
| 摄像头（C/D） | 第 7 节第 4 条通过后才上电；识别 OV3660，连续采集无持续掉帧 |
| 共片选双眼 | Y 型线下 40MHz 无花屏；不稳则降到 20MHz 并记录 |

## 10. 实施第一步需要定稿的选型

这些在实施计划的第一批任务里完成，每项都有验收条件：

| 项 | 验收条件 |
|---|---|
| IP5306-I2C 料号 | 立创有库存；手册确认可经 I2C 关闭轻载关机、调充电电流、关闭充电；关机电流 < 50µA |
| 电池防反接电路 | 满足 3.3 节「插着 USB 时反接也不损坏」；单独评审 |
| USB-C 16P 型号 | 比一期小、嘉立创可贴、有库存 |
| LIS2DH12、MAX98357A、XH2.54 卧贴、SH1.0 卧贴、2.54 贴片排针 | 立创有库存；封装与实物尺寸核对 |
| 舵机 5V 储能电容 | 贴片、矮；按两只舵机同时启动不让系统 5V 跌破 4.5V 选值 |
