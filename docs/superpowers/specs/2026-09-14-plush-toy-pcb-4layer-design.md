# 毛绒玩具主板 4 层 PCB 设计方案

**日期**：2026-09-14
**目标**：把 `plush-toy` 面包板原型转成一块 4 层主板，固件引脚分配不变（以 `main/boards/plush-toy/config.h` 为唯一事实来源）
**状态**：设计输入，尚未开始原理图

---

## 1. 为什么要做板，以及这块板必须解决的问题

面包板原型已经暴露出三个不是固件能修的问题，PCB 的首要任务是把它们从结构上消除：

| 原型上的问题 | 根因 | 本方案的对策 |
|---|---|---|
| I2C 偶发坏读，空闲丢帧率 4% 到 10%（README「量总线健康」） | 四块模块各带上拉并联到约 2.0k、飞线长、无地平面 | 板上只放一组上拉；传感器芯片直接贴在主板上；I2C 走在完整地平面上方（6.4 节） |
| 2026-09-13 事故：加热回路误接到开发板供电，LDO 烫手，持续欠压复位 | 大电流与逻辑电源在面包板上无物理隔离 | 电机/加热电源与逻辑电源是两个独立输入，**PCB 上不存在任何能把二者连起来的铜**（第 4 节） |
| MOS 模块栅极是否自带下拉未知，悬空时上电可能自行导通 | 用现成模块，内部电路不可控 | 加热 MOSFET 板载，栅极下拉写进原理图（5.2 节） |

## 2. 范围

**本期包含**：ESP32-S3 模组、3V3 电源、摄像头接口、双圆屏接口、I2S 麦克风与功放、PCA9685 舵机驱动、MPR121 触摸、MPU6050 运动、ADS1115 测温、加热 MOSFET、USB-C。

**本期不含**：
- **电池与充电**。原设计即为「本期 USB 5V 带线」。电源架构为电池预留入口（4.4 节），但不画充电电路。
- **屏幕与摄像头本体**。二者走线缆接到主板，不贴在主板上。
- **天线设计**。用带 PCB 天线的模组，不做外置天线。

## 4. 电源架构

### 4.1 两个独立输入

| 电源域 | 输入 | 负载 | 设计电流 |
|---|---|---|---|
| **逻辑域** `VBUS` | USB-C 5V | 3V3 降压、摄像头 LDO、功放 | 按 1.5A 设计，USB 口实际能给多少取决于主机 |
| **功率域** `VMOT` | DC 5V，XT30 或 5.08mm 螺丝端子 | 两个 SG90、加热膜 | **≥ 3A** |

**两个域的正极在 PCB 上没有任何连接**，包括不经过二极管、跳线、0Ω 电阻的连接。这是 2026-09-13 事故之后的硬约束。只在 4.3 节规定的一个点共地。

功率域按 3A 设计的依据：SG90 堵转约 700mA ×2，加热膜 1A，合计约 2.4A。现有 5V/2A 电源余量不足，体温方案 2.6 节已记录。

### 4.2 逻辑域功率预算

| 负载 | 峰值电流（3V3） | 依据 |
|---|---|---|
| ESP32-S3 Wi-Fi 发射 | 约 350-500mA | 模组手册的 TX 峰值，需按实际模组手册核对 |
| 双 GC9A01 圆屏（含背光） | 约 80mA | 单屏约 40mA，需实测 |
| OV2640 摄像头 | 约 100mA | 经 2.8V / 1.2V LDO 取自 3V3 |
| PCA9685 / MPR121 / MPU6050 / ADS1115 | < 20mA | 逻辑侧 |
| **合计** | **约 700mA** | |

**3V3 用同步降压，不用 LDO**。5V 降到 3.3V 时，LDO 在 700mA 下要耗散约 1.2W，SOT-223 封装在毛绒里散不掉。选型要求：输出 ≥ 1.5A，开关频率 ≥ 1MHz 以缩小电感，带软启动以避免 USB 插入时的浪涌。

降压电感和开关节点放在远离模组天线和麦克风的一侧。

### 4.3 接地

- **L2 是一整片 GND**，逻辑地。
- **功率地 PGND** 走在 L1 和 L4 上的宽铺铜里：舵机插座、加热插座、MOSFET 源极、`VMOT` 输入的负极。
- **PGND 与 GND 只在一个点汇合**，位置在 `VMOT` 输入端子旁、大电容负极处。舵机和加热的回流电流就不会流过逻辑地平面。面包板上的 I2C 坏读，有一部分可能就是回流电流抬高了地电位造成的。
- 汇合点用一个 0Ω 电阻或短铜桥实现，调试时可以断开，分别测两个域。

### 4.4 电池预留

**本期不做任何电池预留，板上没有 `VBAT` 网络。**（2026-09-15 核对时发现原文写了「留一个 `VBAT` 焊盘和对应的升压位置」，但 `board_spec` 里从来没有这个网络。以板子为准，并把决定改成下面这条。）

理由：单独一个 `VBAT` 焊盘没有用。锂电池是 3.0–4.2V，本板逻辑域要 5V（`VBUS`，功放直接取它）和 3.3V（降压输出）。要真的用电池，配套的升压、充电、电池保护、电量检测一个都不能少，这已经是一块独立的板子，不是一个焊盘。留一个不知道怎么接的焊盘是负债：它会让人以为电池这件事已经预留好了。

**以后要上电池，做一块独立的电池板**（充电 + 升压 + 保护），输出 5V，从现有的 USB-C 或 `J_VMOT` 给主板供电。主板一处都不用改。

**不预留 USB 与电机电源的自动切换电路**：它正是事故里「两个域连在一起」的那条路径，要做就在电池那一期单独评估。

## 5. 加热电路（板载替代 MOS 模块）

### 5.1 为什么不再用 OPEN-SMART 模块

- 栅极下拉是否自带要实测才知道（体温方案 2.3 节），而 PCB 上可以直接画出来。
- 模块的 `VCC` 与 `POWER` 引脚容易接错，事故就是这样发生的。板载之后接线只剩一个两针插座。

### 5.2 原理图

```
 VMOT ──────────────────────────────► J_HEAT 1（到板外 KSD9700 → 加热膜）
                                      J_HEAT 2（加热膜另一端）
                                         │
                                        D ┐
 PCA9685 LED15 ──[100Ω]──┬────────── G  ┤ Q_HEAT（逻辑电平 N-MOSFET）
                         │              S ┘
                       [100kΩ]           │
                         │              PGND
                        PGND
```

| 器件 | 要求 | 理由 |
|---|---|---|
| Q_HEAT | 逻辑电平 N-MOSFET，**Vgs = 2.5V 时 Rds(on) ≤ 50mΩ**，Id ≥ 4A，SOT-23 或 SOT-23-6 | PCA9685 由 3V3 供电，输出高电平约 3.3V，必须在这个栅压下完全导通。1A 电流、50mΩ 时管子只发热 50mW |
| 100kΩ 栅极下拉 | **必贴** | PCA9685 上电之前、复位期间栅极都不能悬空 |
| 100Ω 栅极电阻 | 贴在 MOSFET 旁 | 抑制栅极振铃 |
| J_HEAT | 额定 ≥ 3A 的两针插座，如 JST-VH | JST-XH 的 3A 额定值是在理想条件下测的，长期 1A 在毛绒里散热差，留余量 |

加热膜是纯阻性负载，不需要续流二极管。

### 5.3 KSD9700 放在板外

KSD9700 必须**紧贴加热膜**才能感温，不能放在主板上。它通过线缆串在加热膜的一根引线上，主板只提供两针插座。PCB 丝印在 J_HEAT 旁标注「必须串 KSD9700 65℃ 常闭」。

### 5.4 可选的第二道硬件断电

体温方案 3.5 节指出：ESP32 死机时 PCA9685 会保持最后写入的输出。KSD9700 能兜住这个场景，但板上可以再加一层：

**PCA9685 的 `OE` 脚接一个外部看门狗的输出**，ESP32 停止喂狗时 `OE` 拉高，全部输出关断，舵机也会一起泄力。

代价是 GPIO 已全部用完，喂狗信号无处可接。**本期不做**，只在 `OE` 上预留一个 10kΩ 下拉和一个测试焊盘，为改版留余地。

## 6. 叠层与各接口布线

### 6.1 叠层

```
L1  信号 + 器件      高速线优先：SPI、DVP、USB、I2S
L2  GND（整层）      禁止走线，禁止开槽
L3  电源             3V3 主平面；2.8V、1.2V 小块铺铜；VBUS 局部铺铜
L4  信号 + 器件      低速线：I2C、按键、LED、触摸电极走线；PGND 与 VMOT 宽铺铜
```

板厚 1.6mm，用板厂的标准 4 层叠层（例如嘉立创 JLC04161H-7628），**线宽按该叠层用板厂阻抗计算器算**，不在这里拍数字。需要控阻抗的只有 USB 差分 90Ω。

VMOT 的宽铺铜走在 L4，与 L3 的 3V3 平面之间隔着 L2 的地，避免两个域耦合。

### 6.2 ESP32-S3 模组与天线

- 模组放在**板子边缘**，PCB 天线部分伸出板边，或者天线正下方**所有层都净空**，净空尺寸按乐鑫模组手册的 layout 指南。
- 天线附近不放：降压电感、加热 MOSFET、舵机插座、摄像头 FPC。
- 模组底部的 GND 焊盘打满过孔到 L2。

### 6.3 摄像头 DVP（OV2640）

| 项 | 要求 |
|---|---|
| 接口 | 24 针 0.5mm FPC 座，引脚定义按所用摄像头模组核对 |
| 供电 | 板上 2.8V（AVDD）与 1.2V（DVDD，部分模组为 1.5V，按模组手册）两路 LDO，DOVDD 取 3V3 |
| 引脚 | D0-D7：GPIO11/9/8/10/12/18/17/16；XCLK GPIO15；PCLK GPIO13；VSYNC GPIO6；HREF GPIO7 |
| 布线 | D0-D7 与 PCLK 走 L1，等长误差控制在 5mm 内；**XCLK（20MHz）单独走线**，两侧包地并打地过孔 |
| SCCB | SIOC GPIO5 / SIOD GPIO4，走摄像头专用的 `I2C_NUM_1`，**不与主 I2C 总线相连** |

### 6.4 主 I2C 总线（`I2C_NUM_0`，100kHz）

| 项 | 要求 |
|---|---|
| 引脚 | SDA GPIO44，SCL GPIO3 |
| 挂载 | PCA9685 0x40、ADS1115 0x48、MPR121 0x5A、MPU6050 0x68，全部贴在主板上 |
| 上拉 | **全板只有一组 4.7kΩ**，靠近 ESP32 放置。这是面包板上并联到约 2.0k 这一问题的根治办法 |
| 布线 | 走 L4，参考 L2 地；远离 XCLK、SPI CLK 与降压开关节点 |
| 测试点 | SDA、SCL、GND 各一个，方便挂逻辑分析仪 |

GPIO3 是 JTAG 信号源选择 strapping 脚。默认 eFuse 下它不起作用，4.7kΩ 上拉无害；**如果以后烧写了相关 eFuse，需要复查**。

### 6.5 双屏 SPI（40MHz）

| 项 | 要求 |
|---|---|
| 引脚 | MOSI GPIO14，CLK GPIO38，DC GPIO47，RST GPIO21，CS_L GPIO45，CS_R GPIO46 |
| 接口 | 两个 8 针插座（RST / CS / DC / SDA / SCL / GND / VCC / BL），或改为 FPC |
| 背光 | 两屏 BL 并联，接 AO3401A 高边开关（Q_LCD_BL）的漏极；GPIO48 经 100Ω 驱栅，100k 上拉保证上电默认灭 |
| 串联电阻 | CLK 与 MOSI 在 ESP32 端各串 33Ω，抑制长线反射。**两块屏共用 CLK/MOSI，线缆越长越需要它** |
| 线缆 | 每块屏的线缆尽量 ≤ 10cm。超过就把 `DISPLAY_PCLK_HZ` 退回 20MHz（`config.h` 已注明 20MHz 实测稳定） |

**GPIO45 与 GPIO46 都是 strapping 脚**：
- GPIO45 决定 VDD_SPI 电压，N16R8 模组要求它在复位时为低电平。
- GPIO46 影响 ROM 下载模式和日志输出。

所以**这两根 CS 线上不得加上拉**，也不能接任何在上电瞬间会把它拉高的电路。面包板上能正常启动，说明现有屏模块没有强上拉；**换屏模块时必须复查**。

### 6.6 USB（GPIO19/20）

- USB-C 母座，CC1/CC2 各接 5.1kΩ 下拉到 GND，这样主机才会供电。
- D+/D- 按 90Ω 差分走线，全程走 L1，不打过孔，尽量短。
- 入口处放低电容 USB ESD 保护器件。
- VBUS 串自恢复保险丝。

### 6.7 音频（I2S）

> 2026-09-15 委托方确认：功放用 MAX98357A 或 HT517（板上按 MAX98357A 画，换 HT517 前须对数据手册核封装与针序）；
> 麦克风改为**外接模块**，兼容 INMP441 / ICS43434 / ZTS6672，板上只留 `J_MIC` 6 脚座。
> 代码是通用的 I2S simplex 配置（`NoAudioCodecSimplex`），不绑定具体型号。

| 项 | 要求 |
|---|---|
| 麦克风 | WS GPIO1，SCK GPIO2，DIN GPIO42。**外接**：`J_MIC` 6 脚 SH 座，针序 VDD GND SD WS SCK L/R，末脚为 GND 即左声道。板载方案要求主板本身放在玩偶能「听见」的位置，塞进胸腔就废了，故改外接 |
| 功放 | DOUT GPIO39，BCLK GPIO40，LRCK GPIO41。**供电取 VBUS 5V，不取 3V3**：峰值电流大，从 3V3 取会在播放时拉低 ESP32 的电压 |
| 喇叭 | 两针插座。功放输出是 BTL 差分，**喇叭两端都不能接地** |

### 6.8 触摸电极（MPR121）

- 目前只用 ELE0，接头部电极。其余 11 路各引到一个焊盘，方便以后扩展。
- 电极走线**尽量短**，两侧保持间距，**正下方的 L2 地挖空，或改为网格铺地**。整片实心地会让基线电容太大、灵敏度下降。
- 远离 SPI CLK 和舵机 PWM 这类快速跳变的信号。

### 6.9 运动传感器（MPU6050）

- 贴在板子中部，靠近安装孔，让它测到的是玩具身体的运动，而不是板子自身的弯曲。
- 远离舵机插座：舵机振动会被读到，固件里已经有 400ms 抑制窗口，但物理上离远一点总归更好。

### 6.10 测温（ADS1115）

- 分压电阻 10kΩ 1% 和 0.1µF C0G 电容**贴在 A0 引脚旁边**，不要放在 NTC 插座那一侧。
- NTC 插座放在靠近加热插座的板边，缩短到加热膜的线缆。
- A0 走线远离 VMOT 和加热电流路径。加热通断时的地电位跳动会直接叠加到读数里，这正是 4.3 节要把 PGND 分开的原因之一。
- **预留 A1 比例测量**：3V3 经两颗电阻分压后接 A1，默认不贴。体温方案 9 节提到，这样可以消除 3V3 轨漂移造成的约 0.3℃ 残差。

## 7. 布局分区

```
┌──────────────────────────────────────────────────┐
│ [天线净空]  ESP32-S3 模组        USB-C  降压 3V3   │ ← 逻辑区（上）
│                                                  │
│ 摄像头FPC  2.8V/1.2V LDO   左屏座   右屏座   麦克风 │
│                                                  │
│ MPR121  MPU6050(居中)  ADS1115+分压  PCA9685     │ ← 传感区（中）
│ 触摸电极焊盘                          I2C 测试点   │
│ ─────────────── 星形汇合点 ────────────────────── │
│ VMOT输入  大电容  舵机CH0 舵机CH1  Q_HEAT  J_HEAT  │ ← 功率区（下）
│ 功放  喇叭座                           NTC座      │
└──────────────────────────────────────────────────┘
```

原则：**天线在一端，功率在另一端，传感器夹在中间**。

外形尺寸和安装孔位置取决于玩具内部空间，**待定**（见第 10 节）。

## 8. 引脚总表

与 `config.h` 完全一致，PCB 不做任何改动：

| 2 | I2S 麦克风 SCK | 21 | 屏 RST |
| 3 | 主 I2C SCL（strapping） | 26-32 | 模组内部 Flash，**不可用** |
| 4/5 | 摄像头 SIOD/SIOC | 33-37 | 模组内部八线 PSRAM，**不可用** |
| 6/7 | 摄像头 VSYNC/HREF | 38 | 屏 SPI CLK |
| 8/9/10/11/12 | 摄像头 D2/D1/D3/D0/D4 | 39/40/41 | I2S 功放 DOUT/BCLK/LRCK |
| 13 | 摄像头 PCLK | 42 | I2S 麦克风 DIN |
| 14 | 屏 SPI MOSI | 43 | 控制台 UART TX，**保留**，引到测试点 |
| 15 | 摄像头 XCLK | 44 | 主 I2C SDA |

| 47 | 屏 DC | 48 | 双眼背光 PWM（低电平点亮） |

**已无空闲 GPIO。** 以后要加任何需要 GPIO 的功能（看门狗喂狗、电池检测、MPR121/MPU6050 中断），都必须先让出引脚。

> 2026-09-15 变更：屏幕改用带独立 BL 引脚的型号后，板载 RGB 状态灯（D_LED / C_LED）撤销，GPIO48 改作两眼共用的背光 PWM（约 25kHz）。眼睛本身已能表达设备状态，独立状态灯价值不高；换来的是统一亮度调节和休眠关背光。摄像头、音频、USB、SPI 和 strapping 脚均不受影响。

## 9. 可制造性与调试

| 项 | 要求 |
|---|---|
| 按键 | BOOT（GPIO0）、RESET（EN），都贴在板上 |
| EN 脚 | 10kΩ 上拉 + 1µF 对地，保证上电复位时序 |
| 测试点 | 3V3、VBUS、VMOT、GND、PGND、SDA、SCL、TX(GPIO43)、Q_HEAT 栅极 |
| 丝印 | 两个电源输入标清极性和「电机/加热专用」；J_HEAT 标「必须串 KSD9700」；舵机插座标 CH0=左 / CH1=右 |
| 首板 | 电源部分先单独焊接、单独上电验证，确认 VMOT 与 3V3 之间开路后再贴模组 |

### 首板上电检查顺序

1. **不上电，量电阻**：VBUS、3V3、VMOT 各自对 GND 不短路；**VMOT 对 3V3、VMOT 对 VBUS 都应开路**。
2. 只接 USB：3V3 电压正确，降压芯片不发热。
3. 只接 VMOT：3V3 应为 0V。如果有电压，说明两个域之间有漏电通路。
4. 贴模组，烧写现有固件，读 `status`：`servo_present` / `touch_present` / `motion_present` / `thermal_available` 全部为 true。
5. 跑 `tools/plush_toy_i2c_trial.py`，与面包板基线对比空闲丢帧率。**这是验证这块 PCB 值不值得做的核心指标**。
6. 加热插座先接一个 5Ω / 10W 功率电阻代替加热膜，用 `thermal-force-duty` 验证 MOSFET 温升，再接真正的加热膜。
